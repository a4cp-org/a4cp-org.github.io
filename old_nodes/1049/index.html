First International CSPlib Sprint Event, September 5th, 2015, UCC Cork, Ireland

ACP

Call for Participation#

On the Saturday after the CP 2015 conference (http://booleconferences.ucc.ie/cp2015), we will organise a Sprint event to make improvements to the CSPlib problem library (http://csplib.org). This event is an informal gathering of interested researchers and practitioners. We will add new, interesting problems, add new solutions to existing problem instances, and work on improving references and links in the library. This is the perfect way to end the trip to Cork for the CP conference and serve as an excellent starting point to contributing to a valuable resource for the CP community.

You should attend the event if

  • you have new problems to add to the CSPlib, but are unsure how to do this
  • have developed new solutions to existing problems
  • are interested in modelling problems using constraint programming
  • want to earn hands-on experience with the tools used for CSPLib
  • have a new solver that you want to evaluate on problems from the CSPlib

The event will start at 9:30 in the morning, and last until 18:00. Most time will be spend in small teams to work on the library, but there also will be short tutorials on relevant topics.

If you want to participate, send an email to helmut.simonis@insight-centre.org . Problem suggestions and new, existing data sets are also welcome.

Further details will be posted on the CP website at http://booleconferences.ucc.ie/cp2015csplib
